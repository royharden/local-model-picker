# Limitations

Status: **construction complete - runtime unverified**. Source inspection establishes intended behavior only. No dependency install, type-check, lint, test, build, CLI, eval, simulation, browser journey or live sweep has run. Results remain pending; the case study is **not yet measured**.

## Accuracy and statistics

- Thirty fixed items are a small, heterogeneous sample. One pass at temperature zero is not repeated accuracy measurement; generation can still vary across runtime versions, hardware and implementations. The bank cannot establish general capability or task suitability.
- GSM8K/MMLU probably occur in model training data; contamination can inflate absolute scores. Comparing quants does not eliminate it. Sourced rows and revisions are recorded, but independent source/provenance verification remains deferred. Original instruction items use IFEval-style methodology, not an official IFEval score.
- Exact paired sign tests discard concordant pairs and often have little power here. “Tied within noise” means failure to distinguish, never equivalence. The leader is selected after observing accuracy; tests have no multiplicity correction. With several candidates, nominal alpha is not a calibrated family-wise error guarantee. Wilson intervals describe individual proportions, not a confidence interval for the selected winner or paired difference. The confidence label is a closed heuristic list, not a probability.
- **F4:** the same builder authored the synthetic dev and held-out responses and their labels. Path isolation and one gated held-out evaluation prevent accidental loading; they do not create independent human annotation or blind evaluation. The recorded seed accompanies an explicit hand-assigned split, not a seededSplit-generated assignment. Correctness and exact extraction agreement are reported separately, with combined agreement and every miss named. The proposed correctness target is not evidence of reliable grading on real responses. Add independent, never-tuned real-response checks after the first live sweep and report them separately.
- Deterministic graders have bounded grammars: numeric words/fractions and correction markers are conservative; letter extraction and JSON boundaries can reject valid answers or accept misleading ones. Capping before redaction and think removal can lose a later correct answer; unfinished thinking fails closed. Structured thinking and inline thinking are different mechanisms. Redaction can alter answer text. Audit rulings may change correctness/extraction but remain human corrections, not untouched evidence.
- **F7:** fourteen hand-authored recommender scenarios expand into seventeen objective, hardware-override and ruling cases. They are specification tests inspected during construction, not held-out selection evaluation; the variants are not independent trials. Baseline expected-pick agreement uses the frozen recommender target. Fastest-only and accuracy-only ignore limits deliberately, and baselines have no statistical tie flag. Zero counted known violations for an unavailable or unmeasured estimate pick does not show compliance.
- Simulation uses independent Bernoulli answers across candidates/items/trials, fixed true accuracies and a fixed seed. It omits shared item difficulty and candidate correlation. It selects the observed leader post hoc, then applies the one-sided test. Positive-gap non-rejection is called false tie; a significant worse-candidate win is wrong-direction false win. At the null, any declared difference is false difference, and non-rejection is unresolved, not false tie. Binomial MCSE quantifies finite simulation trials only. These rows are not actual paired power, real model performance or proof of equivalence.

## Timing, memory and selection

- Speed changes with thermals, background load, prompt caching, concurrent users, drivers, model loading and runtime versions. Three repeats and descriptive ranges do not remove those effects. The scalar is the slowest per-prompt median; latency is the largest per-prompt median. Short or truncated generations may not represent the user's workload.
- Client TTFT and time to first answer depend on streaming and thinking detection; their semantics and cancellation handling need a controlled live run. Runtime token counts/durations are reported values, not independently calibrated instruments. Mock uses virtual time; synthetic fixture wall-clock values are authored data, not measured host performance.
- Memory is sampled `/api/ps` total residency and minimum observed offload fraction, not a guaranteed peak or process RSS presented as VRAM. The optional `nvidia-smi` peak sampler was omitted (`nvidiaPeakBytes` remains null). Apple unified-memory and partial-offload semantics are unverified on actual hardware; CPU-only/unknown probes preserve unknowns. “Full GPU” is an observed fraction threshold, not proof every operation runs on GPU.
- Estimate-only considers installed weights and captured free memory. It excludes KV cache, runtime overhead and changing free memory. Unknown quant/parameter metadata can exclude candidates. Its choice can be unmeasured, so limit compliance is then unknown. It is unavailable for remote/mixed hardware or unknown budgets.
- Saved files are snapshots. Latest whole-measurement supersession avoids splicing but cannot remove temporal drift. Mixed-hardware override is always low confidence. A remote group describes one unknown server collection, never the local machine; remote identity cannot safely join separate collections.
- Only Ollama is supported. No model downloads, other runtimes, custom item banks, multi-GPU, energy, perplexity, telemetry or hosted leaderboard are implemented. Jev is outside this MVP; no API key enables a hidden experiment.

## Files, audit and portability

- The synced temporary-file plus atomic hard-link writer refuses existing targets; unsupported hard-link filesystems fail without a rename fallback. Actual Windows/OneDrive filesystem behavior, cleanup, concurrent publication and interrupted partial-file recovery are unverified. This is not a promise of crash durability for the directory entry.
- The run-size estimate is approximate; the final serialized byte cap is authoritative. Cap failure can prevent saving a long collection. Cancellation/abort paths and cleanup ownership checks need tests and a live check; concurrent activity on Ollama can defeat a simple model-residency picture.
- Run JSON contains measurements and append-only rulings, not custom selection settings or an embedded item bank. Save the Markdown report, reapply objective/constraints/group/flags after import, and export each run in a multi-run decision. Audit cannot supply unknown expected answers for a foreign bank. The viewer's in-memory workspace resets on refresh.
- Responses, tags and imports are untrusted data. Rendering/escaping, redaction and caps are source-level safeguards awaiting validation. Redaction does not guarantee removal of every personal detail or secret; inspect exports before sharing. Bare usernames are intentionally not redacted in graded answer text to avoid corrupting answers.
- “API cost zero” means no billed external API calls in this local tool/evaluator. It excludes hardware, electricity, storage and user time. Neither synthetic timing nor this cost convention is a cost/performance claim.
- Node/package compatibility, tests, browser downloads, exported package subpaths, OS probes and Bolt portability remain deferred. There is no lockfile until activation. Bolt can host the static viewer; native collection stays local. No cloud resources, GitHub import or deployment are verified.
